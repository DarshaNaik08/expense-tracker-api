# Expense Tracker API

ASP.NET Core Web API backend for the Expense Tracker application—handling expense CRUD operations, transaction tracking, and category management.

> **Frontend Client:** This API powers the Angular application at [DarshaNaik08/expense-tracker-ui](https://github.com/DarshaNaik08/expense-tracker-ui).

## Tech Stack
- **.NET / ASP.NET Core Web API** (C#)
- **Entity Framework Core / SQL Server**

## Getting Started
1. **Clone the repository:**
   ```bash
   git clone [https://github.com/DarshaNaik08/expense-tracker-api.git](https://github.com/DarshaNaik08/expense-tracker-api.git)
   cd expense-tracker-api/Expenses.API
   ```
2. **Configure Database:**
   Ensure SQL Server is running locally (the default connection string in `appsettings.json` targets `localhost` and `Expenses-Db`).
3. **Run the API:**
   ```bash
   dotnet run
   ```
